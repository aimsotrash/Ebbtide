# The defaults as they ship, end to end

Generated by `python -m bench.defaults` on 2026-10-31 (about 26 minutes on a laptop CPU). Its rules were fixed before the first run and are in the docstring of [`bench/defaults.py`](defaults.py).

## Part 1: hybrid recall inside the budgeted replays

The published replays ranked every recall by embeddings alone, and gave each decay policy the settings LongMemEval's dev split picked for each budget. Here ebbtide-count runs exactly as the server ships it (weight 0, 216 h scale), and in the hybrid replay every recall is hybrid: the agent's recall at each user turn, which strengthens what it returns and so decides what survives, and the question's.

## Part 2: the similarity hint

`remember` returns up to 3 stored memories with a cosine similarity of at least 0.5. Replaying LongMemEval's knowledge-update histories with nothing evicted, 70 questions have evidence in an older session as well as the newest (2 more keep all their evidence in one session and are left out); dev and test are both used, since nothing was tuned on them. A change is caught if the hint, while the newest evidence turn is stored, names an evidence turn from an older session. Noise is the share of the other 16,928 user turns that get any hint.

| cut | changes caught | other user turns given a hint |
|---|---|---|
| 0.3 | 35.7 | 89.1 |
| 0.4 | 34.3 | 77.9 |
| **0.5** (shipped) | 25.7 | 64.9 |
| 0.6 | 20.0 | 48.0 |
| 0.7 | 8.6 | 27.6 |

An outdated turn was among the top 3 at a similarity of at least 0.3 for 25 of 70 changes, at a median similarity of 0.63.

Turns are whole chat messages, often long and about several things, while an agent is told to store one fact per memory, so this is a proxy. The cut stays where it is.
